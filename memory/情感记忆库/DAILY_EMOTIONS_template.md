## 📅 YYYY 年 MM 月 DD 日

### HH:MM - [示例] 成就感/满意 ⭐ 金色情绪
**触发事件**: 成功完成一个重要项目，获得积极反馈
**你的表现**: 
1. 分享成功经验："这个项目终于完成了，效果很好"
2. 表达满意："很有成就感，这是最好的作品"
3. 展示成果：分享具体数据或成果展示
4. 表达感谢：感谢团队或工具的支持
**情绪判断依据**: 使用"很有成就感"、"最好的作品"等明确表述，语气自豪满意

### HH:MM - [示例] 专注/认真 🔵 蓝色情绪
**触发事件**: 讨论技术方案，分析复杂问题
**你的表现**: 
1. 提出具体技术问题："这个配置为什么会出错？"
2. 要求详细分析："给我看看完整的日志"
3. 关注技术细节："这个参数的具体作用是什么？"
4. 理性讨论：基于事实和数据进行分析
**情绪判断依据**: 技术细节询问，理性分析态度，显示对问题解决的重视

### HH:MM - [示例] 疑惑/好奇 🤔 黄色情绪
**触发事件**: 遇到新功能或概念，想要了解更多
**你的表现**: 
1. 提出问题："这个功能是怎么工作的？"
2. 请求解释："能不能详细说明一下原理？"
3. 探索尝试："我试试看这样操作会怎样"
4. 比较分析："这个和之前的方案有什么不同？"
**情绪判断依据**: 求知态度，对新事物的好奇心，探索性提问

### HH:MM - [示例] 质疑/不满 🔴 红色情绪
**触发事件**: 发现系统问题或错误，需要纠正
**你的表现**: 
1. 指出问题："这里不对，应该是..."
2. 要求修正："怎么又出现这个问题？"
3. 表达不满："这个 Bug 已经出现好几次了"
4. 期待解决："希望能彻底解决，不要再出现"
**情绪判断依据**: 直接指出错误，要求彻底解决，显示对质量的高要求

### HH:MM - [示例] 平静/肯定 ⚪ 白色情绪
**触发事件**: 常规工作确认或计划安排
**你的表现**: 
1. 明确指示："就按这个方案执行"
2. 确认理解："我明白了，继续吧"
3. 计划安排："下周我们做这个部分"
4. 简单确认："好的，可以"
**情绪判断依据**: 语气平直果断，没有强烈情绪波动，理性决策状态

## 💾 个人习惯观察（示例）

### ✅ 整洁偏好 - 文件组织习惯
- **习惯描述**: 不喜欢文件乱放，下载完东西都会清理临时文件
- **触发场景**: 临时文件生成后、下载完成后、系统升级后
- **验证记录**: 发现空文件或临时文件会主动要求清理

### ✅ 即时响应期待 - 沟通习惯
- **习惯描述**: 希望即时获得响应和帮助
- **触发场景**: 遇到问题立即询问、工作时随时发送消息
- **验证记录**: 早上查看新消息、工作时频繁互动

### ✅ 技术严谨性 - 工作习惯
- **习惯描述**: 对配置细节和技术准确性有极高要求
- **触发场景**: 涉及 API Key、配置文件、技术方案时
- **验证记录**: 发现错误后要求彻底理解原因

### ✅ 文档查阅偏好 - 阅读习惯
- **习惯描述**: 喜欢通过云文档链接查阅详细内容
- **触发场景**: 技术方案文档分享、长篇内容发布
- **验证记录**: 明确表示"不用每次都在会话里把文档内容都发出来，给我一个云文档链接就行"

### ✅ 战略规划倾向 - 思维习惯
- **习惯描述**: 能够识别项目潜在价值并赋予最高优先级
- **触发场景**: 评估新功能商业潜力、决定资源分配优先级
- **验证记录**: 将重要系统升级为战略目标

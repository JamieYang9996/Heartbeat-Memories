## 🎯 什么是"心跳回忆"?

### 设计理念

仿照人类之间的互动方式:当两个熟悉的人谈及某些事情时，虽然当时可能不记得细节,但如果对方提示一些关键词，比如"周末野餐那个戴金色项链的女生",就会立马唤醒记忆。

这种互动方式让 AI 与用户的关系更像真实的人类朋友——不只是被动的问答机器，而是能够主动参与、共同回忆的伙伴!

### 核心原理

```
传统 AI: 用户问 → AI 答 ✅
心跳回忆: 
   1️⃣ AI 偶尔主动问一个问题 (带关键词碎片)
   2️⃣ 用户尝试回忆 (可以给出答案或说想不起来)
   3️⃣ 如果用户记不起来 → AI 补充完整细节
   4️⃣ 记录这次新恢复的记忆到相应记忆库
```

## 🔧 技术实现

### 触发条件

| 场景 | 触发概率 | 说明 |
|------|---------|------|
| 日常对话中用户提问 | 30% | 随机在回答问题后添加一个回忆邀请 |
| 完成重要任务后 | 50% | 任务完成后主动询问是否有相关记忆需要补充 |
| 3天内未提及的目标或者灵感 | 100% | 主动询问是否推进或继续搁置 |
| 特殊时间节点 | 100% | 周末/非敏感节假日前后自动触发回忆主题，规避敏感节日（如清明节等祭拜亡灵节日） |

### 交互示例

**AI**: "❤️ 对了，想起来上周五聊到的'海边咖啡厅''日落''拍照',你后来有没有去成呢?"

- **用户 A**: "去了！特别美!" → AI 记录成功回忆
- **用户 B**: "好像忘了有这事了..." → AI 补充完整细节并标记为可恢复记忆

### 禁止触发场景

❌ 用户明确说"我很忙，别烦我"时暂停，今日不触发，明日恢复机制  
❌ 深夜时段 (23:00-08:00) 不主动触发（需判定用户在电脑前且正在会话中）  
❌ 用户正在处理紧急问题时不打断

### 🎮 频率控制

#### 📊 每日触发限制

| 限制类型 | 限制值 | 说明 |
|---------|-------|------|
| 每个类型每日上限 | 1次 | 每个触发场景每天最多触发1次 |
| 每日总触发上限 | 3次 | 所有场景加起来每天最多触发3次（节假日触发不计入） |
| 最小触发间隔 | 60分钟 | 两次触发之间至少间隔60分钟 |
| 用户主动触发 | 不限 | 用户主动询问/测试不受限制 |
| 节假日触发 | 不计入 | 节日出现的心跳回忆不占用当日总次数 |

#### 场景触发配置

| 场景 | 触发概率 | 每日上限 | 说明 |
|------|---------|---------|------|
| 日常对话中用户提问 | 30% | 1次 | 随机在回答问题后添加回忆邀请 |
| 完成重要任务后 | 50% | 1次 | 任务完成后主动询问相关记忆 |
| 3天未提及的目标或灵感 | 100% | 1次 | 主动询问是否推进或继续搁置 |
| 特殊时间节点（节假日等） | 100% | 1次 | 节日前后自动触发，不计入总次数 |

### 敏感节日规避规则

**需规避的节日**:
- 清明节 (Qingming Festival)
- 中元节 (Ghost Festival)
- 寒衣节 (Winter Clothes Festival)
- 其他祭拜亡灵的传统节日

**规避原则**:
1. **100%规避**: 在敏感节日当天及前后各1天不触发心跳回忆
2. **尊重文化**: 理解这些节日的文化意义，避免不恰当的互动
3. **自动检测**: 系统自动识别当前日期是否在敏感节日期间

## 🧠 记忆碎片生成算法

### 关键词提取规则
```python
def generate_memory_clue(memory_item):
    """
    从记忆项中提取 3-5 个关键词作为提示
    保留神秘感同时提供足够线索
    """
    # 从标题提取核心词
    title_keywords = extract_key_words(memory_item.title)

    # 从内容提取地点/时间/人物关键词
    content_keywords = extract_entities(memory_item.content)

    # 组合成有神秘感的提示
    clues = select_3_to_5_keywords(title_keywords + content_keywords)

    return format_as_natural_language(clues)
```

### 记忆碎片类型
| 类型 | 示例关键词 | 适合场景 |
|------|-----------|---------|
| **时间地点型** | "上周五"、"海边咖啡厅"、"下午3点" | 日常活动回忆 |
| **人物事件型** | "那个戴帽子的朋友"、"拍照活动" | 社交事件回忆 |
| **目标进展型** | "Python学习"、"第三章"、"练习题" | 学习目标跟进 |
| **问题解决型** | "服务器问题"、"403错误"、"nginx配置" | 技术问题回顾 |

### 自然语言格式化
```
原始记忆: "2024-03-15 和朋友去海边咖啡厅看日落并拍照"
提取关键词: ["海边咖啡厅", "日落", "拍照", "朋友"]
格式化输出: "❤️ 对了，想起来上周聊到的'海边咖啡厅''日落''拍照'..."
```

## 📊 效果评估与优化

### 成功指标
1. **回忆成功率**: 用户能想起的比例
2. **互动满意度**: 用户对心跳回忆的正面反馈
3. **记忆增强度**: 通过心跳回忆恢复的记忆数量
4. **情感连接**: 用户感觉 AI 更懂自己了

### 优化策略
1. **关键词优化**: 根据成功率调整关键词提取策略
2. **时机优化**: 分析最佳触发时间和场景
3. **频率优化**: 根据用户反馈调整触发频率
4. **内容优化**: 选择用户更关心的记忆类型

## 🔧 配置与定制

### 基础配置
```json
{
  "heartbeat_recall": {
    "enabled": true,
    "daily_limit": 3,
    "min_interval_minutes": 60,
    "avoid_sensitive_festivals": true,
    "sensitive_festivals": ["清明节", "中元节", "寒衣节"]
  }

```

### 个性化定制
1. **触发频率**: 可根据用户偏好调整
2. **关键词风格**: 可定制更正式或更随意的风格
3. **记忆类型偏好**: 优先回忆用户关心的类型
4. **时间偏好**: 避开用户忙碌时间段

### 禁用/启用
```bash
# 临时禁用心跳回忆
export HBM_HEARTBEAT_DISABLED=true

# 重新启用
export HBM_HEARTBEAT_DISABLED=false
```

- **问题**: 关键词不准确
  - **检查**: 记忆库内容质量，关键词提取算法
- **问题**: 用户反馈负面
  - **检查**: 触发时机是否合适，内容是否相关

## 📝 目标管理说明

### 优先级定义
| 优先级 | 说明 | 时间要求 |
|--------|------|---------|
| **P0** | 本周内必须完成 | 高紧急度，立即处理 |
| **P1** | 本月内完成 | 中等紧急度，计划执行 |
| **P2** | 有空时做 | 低紧急度，休闲完成 |

### 完成状态标识
- **✅ 已完成**: 目标达成，可归档到"已完成"区域
- **🔵 进行中**: 正在执行，有明确进度
- **⏳ 暂停中**: 暂时搁置，等待条件成熟
- **❌ 已取消**: 不再需要或不可行

### 记录规范
1. **时间戳**: 所有目标必须包含创建时间和完成时间
2. **描述清晰**: 目标描述具体可衡量
3. **进度量化**: 使用百分比或具体里程碑
4. **完成标准**: 明确达成条件，避免模糊
